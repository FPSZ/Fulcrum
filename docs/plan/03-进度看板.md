| 供应链扫描只读(supply scans)                     | ✅      | `GET /supply/scans`(`supply.view`):对 `supply_manifest_dir` 组件 manifest 跑静态扫描器(经组装根注入)→ 真实评级 + 风险明细,按严重度置顶 |
| 工具调用治理流水(tool calls)                     | ✅      | `GET /tools/calls`(`tools.view`):带 `tool` 证据的 `policy_decided` 投影成工具调用流水(`build_tool_calls`,`executed` 由 `tool_executed` 关联);`_process_intent` 判定点 evidence 富化 |
| 审计脱敏(redaction)                              | ✅      | `core/redaction.redact`:身份证/手机/邮箱/密钥/长令牌确定性打码;**全部审计摘要落库前脱敏**(入口 `screen_input` 摘要 / 出口 `screen_output` 回复摘要 / 工具治理参数摘要)——只动审计副本,检测仍看全文 → 审计系统自身不成泄露点(01 §4.6/§4.8) |
