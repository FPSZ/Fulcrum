## 4. 接下来(建议顺序)

1. **后端 M1**:落第一个真实检测器 + 一条真实策略 + 真实审计(替换桩),跑通"拦一种注入并审计"。
2. **前端铺页**:用插件系统接「策略中心 / 审计溯源」页面;给**第二种备份资源(策略)**接导入,验证"不止事件"的扩展。
3. **前后端对接**:定 OpenAPI 契约,事件/审计页接后端真数据。
4. **评测**:评测引擎 + 中文样例集 + 指标报告(M3)。
5. **单容器部署**:按 [04-单容器部署方案](04-单容器部署方案.md) 补"后端托管前端 + Dockerfile",做到一条命令跨平台起服务(方案已规划,**尚未实现**)。
6. **控制台能力(M4)**:按 [05-控制台能力规划](05-控制台能力规划.md) 做**权限组(RBAC)**与 **AI 操作助手**;建议先 RBAC 再助手,让助手从一开始就在权限闸门内运行(方案已规划,**尚未实现**)。
