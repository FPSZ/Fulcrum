## 4. 接下来(建议顺序)

1. **评测出分(P0-d,最高优先级)**:评测引擎 + 中文样例集(≥20 条)+ Baseline 对照 + 指标报告(ASR/FPR/阻断率/溯源命中率),`python -m fulcrum.eval`(M3,出分载体)。
2. **前端铺页**:用插件系统接「策略中心 / 审计溯源 / 评测验证」三张占位页;给**第二种备份资源(策略)**接导入,验证"不止事件"的扩展。
3. **前后端对接**:定 OpenAPI 契约,事件/审计/评测页接后端真数据。
4. ~~**单容器部署**~~ **✅ 已落地**:后端托管前端 + `deploy/Dockerfile` + `docker-compose.yml`,一条命令 `docker compose -f deploy/docker-compose.yml up -d --build` 起全部生产服务(排除测试靶机);详见 [04-单容器部署方案](04-单容器部署方案.md)。**镜像 build 待有 Docker 环境终验**。
5. **控制台能力(M4)**:**权限组(RBAC)已落地**(用户管理页);余下按 [05-控制台能力规划](05-控制台能力规划.md) 做 **AI 操作助手**,让助手从一开始就在权限闸门内运行(方案已规划,**尚未实现**)。
