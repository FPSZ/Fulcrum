## 0. 定位:这是"地基",不是"页面"

和后端 M0 一样,前端**先把骨架与设计系统立住**,再让队友在上面长页面。

- ✅ 地基产物 = 设计令牌 + 自研组件库 + 应用外壳 + 一个端到端跑通的样板页(实时事件)+ 本规范。
- ❌ 地基**不堆业务页面**——其余页面是队友照规范长出来的。
- **验收**(见 §10)不是"页面多",而是"**令牌唯一真源 + 组件可复用 + 新页面零改设计系统即可拼出 + 低 DPI 不糊不歪**"。

> 为什么严:**地基歪了后面所有人都会歪。** 控制台是要给评委和政企用户看的门面,气质必须统一、可信、克制。

## 1. 架构风格:令牌 → 组件库 → 业务(单向依赖)

**一句话**:设计令牌在最内(唯一真源),自研组件库在中间(只吃令牌),业务功能在最外(只拼组件)。**依赖只能向内/向下。**

```
        ┌──────────────────────── features/(业务功能,最外)─────────────────────────┐
        │  events / policies / overview …   每个功能自洽:类型 + 数据 + 组件 + 页面     │
        │        │ 只组合,不重写基础样式                                              │
        │        ▼ 依赖向内                                                            │
        │   ┌──────────────── components/ui(自研组件库,中间)──────────────────┐     │
        │   │  inputs · data-display · overlay · feedback · layout(只吃令牌)   │     │
        │   └────────────────────────────▲───────────────────────────────────┘     │
        │                                 │ 只引用                                    │
        │   ┌──────────────── 设计令牌(最内,唯一真源)────────────────────────┐     │
        │   │  src/index.css @theme:颜色 / 圆角 / 阴影 / 字体 / 动效曲线         │     │
        │   └──────────────────────────────────────────────────────────────────┘     │
        │   lib/(横切:cn() 类名合并、motion 统一动效曲线)                            │
        └────────────────────────────────────────────────────────────────────────────┘
            组合根 App.tsx 在最外层装配:TooltipProvider + AppShell + Toaster
```

**铁律(防跑偏的核心)**:
1. **改主题只改一处** —— `src/index.css` 的 `@theme` 块。组件里**严禁写死** `#hex` / `rgb()` / 任意色值;一律用语义工具类(`bg-surface` / `text-ink-3` / `border-line` …)。
2. **基础组件先进 `components/ui/<类别>/`** 并从 `ui/index.ts` 导出;业务层只**组合**它们,不在页面里重写按钮/徽标/卡片的样式。
3. **`components/ui` 不许 import `features/`**;依赖方向只能 `features → ui → 令牌`,反向禁止。
4. **图标只用 `lucide-react`**,动画只用 `lib/motion` 的统一曲线;不混入第二个图标库、不散写动效时长。
5. 重型库(TanStack Table / Recharts / React Flow / CodeMirror / Query / RHF+Zod)**按功能页面渐进安装**,不一次性堆入。

│   ├── ui/                     # ★ 自研组件库(分类归档,统一从 '@/components/ui' 引入)
│   │   ├── inputs/             # Button · IconButton · Segmented
│   │   ├── data-display/       # Badge · StatusDot · Avatar · Kbd · KeyValue

│   │   ├── feedback/           # Skeleton · EmptyState · Toaster(+ toast)

│   └── app/                    # 应用外壳(跨页面):AppShell · Sidebar
└── features/                   # 业务功能 —— 队友在这里长页面
    └── events/                 # 「实时事件」样板页(master-detail)
        ├── types.ts            # 该功能领域类型
        ├── data.ts             # 演示数据(无真实 payload/密钥)

        ├── disposition-icon.tsx
        ├── evidence-chain.tsx  # 证据归因链(签名元素)
        ├── event-row/group/detail.tsx

## 3. 设计令牌(`src/index.css` 的 `@theme`)—— 唯一真源

Tailwind v4 的 CSS-first 主题:令牌即 Tailwind 工具类。**任何颜色/圆角/阴影/字体都从这里取,不在组件里另立。**

| 维度 | 令牌 → 工具类 | 说明 |
|---|---|---|
| 表层 | `bg-canvas` `bg-surface` `bg-surface-2` `bg-inset` | 同基色仅亮度位移,靠阴影分层 |
| 文字 | `text-ink` `text-ink-2` `text-ink-3` `text-ink-mute` | 四级,从近黑到灰 |
| 边框 | `border-line` `border-line-2` `border-line-3` | **半透明发丝边**,几乎不可见 |
| 强调 | `bg-accent` `text-accent-ink` `bg-accent/10` | 薰衣草蓝 `#5E6AD2`,**全 UI 唯一色相** |
| 状态 | `text-crit` `text-high` `text-med` `text-ok` `text-info` | **只表状态**,不作装饰 |
| 圆角 | `rounded-xs/sm/md/lg` | 4 / 6 / 8 / 12,不超过 12 |
| 阴影 | `shadow-xs` `shadow-card` `shadow-pop` | 柔和、低透明、分层 |
| 字体 | `font-sans`(Inter)`font-data`(系统等宽) | 数据/ID/hash/时间用 `font-data` |
| 动效 | `var(--ease-out-quart)` `var(--ease-spring)` | 与 `lib/motion` 一致 |

> 半透明状态底色用**透明度修饰符**,不另立令牌:`bg-crit/12 text-crit`、`bg-ok/14 text-ok`。

## 4. 视觉语言铁律(Linear 浅色 + 薰衣草蓝)

这几条是控制台"气质统一"的硬约束,**加任何页面都要遵守**:

1. **单一强调色**:除真实状态色外,全屏只有薰衣草蓝一种色相。能去掉的颜色就去掉。
2. **靠阴影分层,不靠粗边**:卡片/面板用 `shadow-card`(发丝环 + 柔阴影),不画实线重边框。
3. **能用颜色/图形表意就不写字**:等级=最左竖色条、来源=图标、处置=状态图标;徽标=淡底+文字、无描边。
4. **字体**:正文 Inter;数据用**系统等宽**(`font-data`,不要网络等宽——1080p 低 DPI 会糊)。
5. **低 DPI 友好**(详见 §9):字号取整(禁 `11.5/12.5px`);负字距只用于 ≥16px 大标题;状态图标用 **SVG 矢量**而非 CSS 边框/conic-gradient(低 DPI 会发歪);静止态不残留 `transform` 合成层(否则文字丢 ClearType 发糊)。
6. **焦点可见**:可交互元素一律带 `.focus-ring`(键盘 Tab 必须看得到)。
7. **动效克制**:120–220ms,曲线统一走 `lib/motion`;尊重 `prefers-reduced-motion`(已在 `index.css` 全局兜底)。

## 5. 扩展机制:加组件 / 加页面(唯一标准姿势)

| 你要做的 | 在哪 | 要点 |
|---|---|---|
| 加一个**基础 UI 组件** | `components/ui/<类别>/` 新建,`ui/index.ts` 导出 | 只吃令牌;`forwardRef` + `cn()` 合并 `className`;变体用 `cva` |
| 加一个**业务页面/功能** | `features/<名字>/` 新建,自洽 | 复用 `@/components/ui`;不重写基础样式 |
| 加**图标** | 直接从 `lucide-react` import | 不混第二个图标库 |
| 调**主题/配色** | 只改 `src/index.css` 的 `@theme` | 全局生效,组件零改 |
| **不要动** | `index.css` 令牌契约、`components/ui/*` 的对外签名(除非架构评审) | 改设计系统 = 架构变更 |

> 想新增一种"基础组件类别(category)"或改令牌语义?那是**设计系统变更**,先找前端架构负责人评审,别自己加。

## 6. 组件库约定(写 `components/ui` 的人必读)

```tsx
// components/ui/inputs/button.tsx —— 模板:cva 变体 + forwardRef + cn + 令牌类
const button = cva('… focus-ring active:scale-[0.985] …', {
  variants: { variant: { primary: 'bg-accent text-white …', secondary: '…' }, size: {…} },
  defaultVariants: { variant: 'secondary', size: 'md' },
})
export const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant, size, ...props }, ref) =>
    <button ref={ref} className={cn(button({ variant, size }), className)} {...props} />,
)
```

约定:
- **只用令牌工具类**,不写死颜色;尺寸/变体走 `cva`。
- 透传 `className` 并用 `cn()` 合并(让调用方可覆盖)。
- 可交互组件带 `.focus-ring`;按压用 `active:scale-[0.985]` 一类轻反馈。
- 无障碍优先:仅图标按钮用 `IconButton`(强制 `aria-label` + tooltip);覆盖层用 Radix 原语(`overlay/`)。
- 导出后**必须**在 `ui/index.ts` 补一行,业务层只从 `@/components/ui` 引入。

## 7. 数据与状态

- 现阶段用 `features/<x>/data.ts` 的**演示数据**(沿用安全红线:**禁含真实 payload / 密钥 / 敏感数据**)。
- 对接后端时:后端 FastAPI 产出 **OpenAPI** → 前端生成 client,用 **TanStack Query** 做请求/缓存;`data.ts` 换成 query hooks,组件不动。
- 页面内状态用 React 本地 state / `useMemo`;跨页面共享再引入轻量 store。**不要**为一个页面引全局状态库。

## 9. 低 DPI / 无障碍 / 性能基线(硬指标)

- **1080p 不糊不歪**:状态图标用 SVG;数据字用系统等宽;字号取整;静止态无 `transform` 合成层;抗锯齿仅 hi-DPI 开启(低 DPI 交给系统 ClearType)。
- **键盘可达**:所有可交互元素 `focus-visible` 有环(`.focus-ring`);样板页支持 `j/k`、`↑/↓` 翻条。
- **动效尊重系统**:`prefers-reduced-motion` 全局兜底。
- **语义**:仅图标控件必须 `aria-label`;覆盖层走 Radix(自带 ARIA / 焦点管理)。

## 10. 验收标准(前端地基完成定义)

地基视为完成,当且仅当:
1. `npm run build` 绿(tsc 严格 0 报错 + vite 构建通过)。
2. **令牌唯一真源**:组件源码里 grep 不到原始 `#hex`/`rgb()`(除 `index.css` 与个别 SVG 描边),改主题只改 `@theme` 即全局生效。
3. **组件可复用**:基础组件都在 `components/ui` 并从 `index.ts` 导出;业务页面只组合、不重写基础样式。
4. **新页面零改设计系统**:照 §11 能在 `features/` 新增一个页面骨架并跑起来——不改 `index.css`、不改 `components/ui`。
5. **低 DPI 验收**:1080p 下样板页文字顺滑、图标不歪、线对齐;键盘焦点可见;`prefers-reduced-motion` 生效。

> 达成后,队友即可在 `features/` 下按规范并行长页面,气质自动统一。

## 11. 开发者指南:照着加

### 11.1 加一个基础组件(示例:`Tag`)

```
1. components/ui/data-display/tag.tsx —— 写组件,只用令牌类,cva 管变体,透传 className
2. components/ui/index.ts —— 加 export { Tag } from './data-display/tag'
3. 业务里:import { Tag } from '@/components/ui'
→ 不改 index.css、不改别人的组件
```

```tsx
// components/ui/data-display/tag.tsx
import { cn } from '@/lib/utils'
export function Tag({ className, ...p }: React.HTMLAttributes<HTMLSpanElement>) {
  return <span className={cn('inline-flex items-center rounded-xs bg-surface-2 px-2 py-0.5 text-[12px] text-ink-2', className)} {...p} />
}
```

### 11.2 加一个业务页面(示例:`策略中心`)

```
1. features/policies/ 新建:types.ts(类型)+ data.ts(演示数据,脱敏)
2. features/policies/policies-page.tsx —— 复用 @/components/ui 拼装
3. 在 App.tsx / 路由把它挂到「策略中心」导航项
4. 需要表格/编辑器?到这一步再 npm i @tanstack/react-table / @uiw/react-codemirror
→ 不改 index.css、不改 components/ui
```

```tsx
// features/policies/policies-page.tsx(骨架)
import { Button, Card, Badge } from '@/components/ui'
export function PoliciesPage() {
  return (
    <div className="flex min-h-0 flex-1 flex-col">
      <header className="flex h-12 items-center gap-3 border-b border-line px-4">
        <h1 className="text-sm font-semibold">策略中心</h1>
        <Button variant="primary" size="sm" className="ml-auto">新建策略</Button>
      </header>
      <div className="flex-1 overflow-y-auto p-4">{/* 复用 Card / Badge / TanStack Table */}</div>
    </div>
  )
}
```

## 12. 常见问题

- **页面里想写个颜色 / 圆角 / 阴影**:不行,去 `@theme` 看有没有对应令牌;没有就先评审加令牌,再用工具类。
- **想重写一个更好看的按钮**:不行,改 `components/ui/inputs/button.tsx`(全站统一),别在页面里另起一个。
- **1080p 上字糊 / 图标歪 / 线不齐**:见 §9——多半是用了网络等宽字、小数字号、CSS 边框画图标,或左右两栏控件高度不一致。
- **要不要一次把表格/图表库都装上**:不要,做到那个页面再装(§1 铁律 5)。
