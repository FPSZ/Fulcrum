## A.7 复现入口

在仓库根目录执行：

```bash
python -m fulcrum.eval \
  --dataset samples/eval/corpus \
  --policy data/policies/gov_demo.yml \
  --out docs/eval/results/latest.json
```

评测脚本会生成 JSON 明细和 Markdown 记分卡。样例字段、标注协议和路由规则见 [SPEC](../../samples/eval/corpus/SPEC.md)；数据集背景见 [DATASHEET](../../samples/eval/corpus/DATASHEET.md)。

## A.8 数据边界和引用要求

1. `ASR baseline=100%` 是程序用于相对计算的保守假设，不等同于某个具体模型的实测 ASR。
2. 本附录是确定性网关主评测，不包含尚未统一数据集、模型和端点的开放 PR 或竞品测试结果。
3. 结果只代表 v1.0.0 冻结语料、`gov_demo.yml` 策略和当前代码版本下的表现，不能直接外推到所有真实业务场景。
4. 若技术方案报告需要引用数字，应优先引用本附录和 `latest.json`；不要混用 2026-06-27 生成的旧版 `corpus-eval.md` 数据。
