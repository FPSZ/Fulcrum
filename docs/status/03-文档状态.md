## 1. 总体判断

项目文档覆盖定位、路线、架构、接口、评测、赛题参考、报告和历史评审,总体完整度较高。主要风险是“历史计划、正式报告、当前代码和当前评测”之间存在时间差,后续 AI 很容易把已经过期的阶段状态或目标性文案误当成当前实现。

阅读时必须先遵循 [AGENTS.md](../../AGENTS.md) 的事实优先级,并优先用当前代码和可复现结果核对实现性声明。

## 4. 已确认的漂移与错误

### 4.1 OpenAPI 副本严重落后

[docs/api/openapi.json](../api/openapi.json) 显示版本 `0.0.0`,只包含约 31 条旧路径,而当前包版本为 `0.5.0`。它缺少当前已经存在的多条接口,包括助手聊天/流式聊天/工具/确认/撤销/重置/审批/模型配置、事件处置、管理设置和团队成员等。

代码已有 [OpenAPI 导出工具](../../src/fulcrum/openapi.py),但现有测试只验证生成函数和输出格式,没有断言入库 JSON 与当前应用契约一致。后续应在 CI 中生成临时 spec 并与入库文件做差异检查。

### 4.2 评测数据说明错误或过期

- `samples/eval/DATASHEET.md` 将良性占比写为 `21% (30/200)`,正确值是 `15%`。
- `samples/eval/corpus/README.md` 仍保留旧 Recall 基线,与当前 `89.4%` 主结果不一致。
- `docs/eval/results/json/` 中有多个历史结果,TP 分别为 134、137;当前本地主结果 TP 为 152。它们不是同一文件的副本。
- `CHANGELOG.md` 的历史数字可以保留,但必须明确是冻结当日或历史重测结果。

### 4.3 前端说明过期

[console/README.md](../../console/README.md) 仍称趋势图和事件流是合成动画,当前总览已经从 `/events` 读取真实事件并按近 15 分钟时间戳分桶。

### 4.4 进度和分支规范时间差

- [进度看板](../plan/03-进度看板.md) 截至 2026-08-31,其中本地提交和 PR 状态早于当前 2026-09-02 HEAD。
- [CONTRIBUTING.md](../../CONTRIBUTING.md) 仍要求从 `dev` 创建功能分支。
- 当前本地实际位于 `dev`,仓库还存在多条历史/临时分支;这与维护者“当前阶段只保留 `main`”的偏好不一致。本状态页只记录冲突,不擅自清理分支。

### 4.5 脚本注释与规范不一致

- `scripts/eval.ps1` 顶部仍写“M0 占位”,实现早已不是占位版本。
- `scripts/demo.ps1` 内置并显示演示管理员账号和口令,且可能触发依赖安装。即使是演示凭据,也不符合仓库“配置与密钥分离、脚本不得依赖个人机器状态”的长期约定。

## 5. 报告与当前实现的差异

[技术方案 Markdown](../report/00-技术方案报告.md)、本地 v4 报告和 DOCX/PDF 报告叙事完整,但以下表述不能直接作为当前实现事实:

| 报告表述 | 当前代码事实 |
|---|---|
| ML classifier + LLM Judge 三级融合 | 两者均有可选实现,默认生产装配只启用规则型检测器。 |
| Judge 可异步降低主链影响 | 前置和出口安全闸不能异步旁路;助手当前流式实现反而暴露了先发送后检测问题。 |
| Action Token 绑定工具、操作者和会话 | 当前 token 只包含工具、操作者和过期时间,没有会话、参数摘要或 nonce。 |
| 受限执行器提供文件、网络和资源隔离 | 当前是进程内执行前检查、线程池超时和字符上限,不是操作系统隔离。 |
| 审计失败进入本地重试队列 | 当前代码没有该队列。 |
| MCP 代理、OTEL 兼容、代码行为检测、动态供应链分析 | 当前代码尚未完整兑现。 |
| 容器工作目录只读、网络默认关闭 | Dockerfile/Compose 没有只读根文件系统或容器网络禁用配置;只有应用层外联白名单默认为空。 |
| 工具风险评分综合工具、参数、来源、归因四维 | `HeuristicRiskScorer` 只计算工具固有风险和参数风险,来源与归因由策略阶段另行使用。 |
| 原始 Baseline 100% 降至 10.6% | 100% 是“恶意样例直达未保护 Agent”的保守假设上界,不是真实模型逐档实测。 |

报告仍可用于方案表达,但提交或答辩前应增加“当前实现/可选增强/规划能力”标识,避免把路线图当成已交付能力。
