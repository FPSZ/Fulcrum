## 这是什么

**枢衡(Fulcrum)** 不改造智能体本身,而是作为安全"支点"旁挂在智能体外侧,把"输入 → 决策 → 工具调用 → 执行"的全过程管控起来,并持续产出可量化的审计与评测证据。兼容 OpenClaw 类及其他具备工具调用能力的大模型应用。

本项目为"挑战杯·揭榜挂帅"擂台赛题目 **XA-202620《面向政企场景的大模型智能体安全关键技术研究》**(发榜单位:中国雄安集团数字城市科技有限公司)的参赛作品。

## 解决的问题

智能体系统在政务办公等场景落地时,带来四类区别于传统软件的新型安全风险:

1. **输入侧污染** —— 提示注入、间接指令污染、知识投毒影响模型决策
2. **供应链风险** —— 插件 / 脚本 / Skill 引入后门、恶意外联、高危调用链
3. **越权与泄露** —— 高权限工具调用、文件读写、命令执行、接口联动
4. **过程不可控** —— 缺乏持续监测、审计溯源与分级处置

行业普遍缺少兼顾「**评测—防护—审计—运营**」的一体化技术。**枢衡补的正是这块空白。**

## 四大能力

| 能力域 | 做什么 |
|---|---|
| ① 攻击识别与风险评估 | 多源输入攻击识别、关联分析、分级评估 |
| ② 工具调用安全管控 | 细粒度权限、动态策略校验、关键操作审批、异常任务链阻断 |
| ③ 供应链安全检测 | 插件 / Skill / 脚本的行为检测、依赖分析、恶意识别与评级 |
| ④ 评测与审计溯源 | 多维度可量化评测、审计证据输出、攻击复现与溯源 |

> 详细范围与深浅分配见 **[项目大方向](docs/plan/00-项目大方向.md)**。
